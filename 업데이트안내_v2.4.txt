Goalie Tracker Pro v2.4

핵심 변경
- 새 경기 버튼 → 실제 경기 / 연습 경기 / 게임 레슨 선택 팝업
- 실제 경기/연습 경기는 기존 기록 방식 유지
- 게임 레슨은 참여 골리 풀을 만들고 A/B 골대에 자유롭게 배치/교체
- 게임 레슨은 SAVE + / GOAL + 방식으로 빠르게 기록
- 이전 교대 이력도 S+/S-/G+/G-로 수정 가능
- 양팀 점수는 각 골대의 GA를 기준으로 자동 계산
- 골리별 전체 SOG/GA/SAVE% 및 A/B 골대별 기록 분리
- 경기 목록: 경기 유형 필터 + 그룹/폴더 필터 + 폴더별 묶음
- 시즌 통계: 골리 / 경기 유형 / 그룹(폴더) 필터
- 실제 경기와 게임 레슨 세이브율을 따로 조회 가능
- 기존 실점 분석/슛 위치/골대 위치 기록 유지
