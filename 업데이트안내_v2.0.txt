Goalie Tracker Pro v2.0
골리 교체 시각 기록 추가

핵심
- 경기 중 골리 교체 시 단순히 골리만 바꾸는 것이 아니라
  '교체 피리어드 + 교체 시각'을 반드시 기록합니다.

예시
선발: 김민수
1P 20:00 경기 시작
2P 08:32 박준호로 교체

타임라인
김민수  1P 20:00 → 2P 08:32
박준호  2P 08:32 → 경기 종료

사용 방법
1. 현재 기록 골리 확인
2. 교체 골리 선택
3. 교체 피리어드 선택
4. 교체 시각 MM:SS 입력 (예: 08:32)
5. '골리 교체 적용' 버튼

이후 SOG / GA / 실점 분석은 새 골리에게 기록됩니다.
경기 상세 및 공유 텍스트에도 교체 타임라인이 표시됩니다.

기존 기능
- 골리별 세이브 기록
- 상대 골리 비교
- 실점 분석
- 슛아웃
- 코치 메모
- 시즌 통계
