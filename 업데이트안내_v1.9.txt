Goalie Tracker Pro v1.9
게임 중심 + 경기 중 멀티 골리 교체 기록

핵심 변경
1. 경기는 이제 '한 경기' 단위로 저장
2. 새 경기에서는 선발 골리만 선택
3. 경기 기록 화면 맨 위 '현재 기록 골리'에서 교체 골리를 선택 가능
4. 골리를 바꾸면 이후 SOG / GA / 실점 분석이 해당 골리에게 별도로 기록
5. 한 경기 안에서 골리별 SOG / GA / SAVE%를 따로 확인
6. 우리팀 골리 전체 TOTAL도 별도 표시
7. 경기 목록은 날짜/상대팀 중심으로 표시하고 출전 골리 기록을 함께 표시
8. 경기 상세에서 출전 골리별 피리어드 및 세이브 기록 확인
9. 시즌 통계는 goalieRecords 기준으로 다시 집계
10. 예전 단일 골리 경기 데이터도 자동으로 1명의 goalieRecord로 변환하여 호환

슛아웃
- 기존 UI 유지
- 우리팀 슛아웃 결과를 입력할 때 당시 '현재 기록 골리'에게 귀속
- 시즌 통계에서 골리별 슛아웃도 집계 가능

GitHub 적용
1. ZIP 압축 해제
2. goalie-tracker 저장소 → Add file → Upload files
3. 파일 전체를 저장소 루트에 업로드
4. Commit changes
5. 1~3분 후 시크릿 창에서 먼저 확인
6. 정상 확인 후 기존 설치 앱을 완전히 종료하고 다시 실행

권장 테스트
- 골리 A로 1P SOG 10 / GA 1 입력
- 현재 기록 골리를 골리 B로 변경
- 골리 B로 2P SOG 8 / GA 0 입력
- 다시 골리 A 선택 시 A 기록이 그대로 남는지 확인
- 경기 완료 후 경기 상세에서 A/B가 각각 표시되는지 확인
- 시즌 통계에서 A와 B를 각각 선택해 해당 경기 기록이 잡히는지 확인
