Goalie Tracker Pro v2.5

추가 기능
1. 저장된 경기 수정 화면 맨 위에 '경기 분류' 추가
   - 실제 경기 / 연습 경기 / 게임 레슨
   - 기존 데이터도 수정 화면에서 분류 변경 가능
2. 수정 화면에 그룹 / 폴더 입력 추가
3. 실점 분석에서
   - 슈터 위치 점 + 골대 방향 라인 표시
   - 실점 위치 점 + 하단에서 목표 지점으로 라인 표시
4. 골대 그림에 골리 실루엣 추가

업데이트 후 확인
- 홈 화면에 v2.5 표시
- 저장된 경기 열기 -> 수정 시 상단에 경기 분류가 보여야 함
- 실점 분석에서 링크장 슛 위치에 선, 골대 그림에 골리 모양과 선이 보여야 함
