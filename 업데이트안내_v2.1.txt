Goalie Tracker Pro v2.1
슛 위치 링크장 도면 추가

변경
- 실점 분석에서 링크장 슛 위치 + 골대 실점 위치를 동시에 기록
- 태블릿/PC에서는 좌우 배치
- 좁은 화면에서는 위아래 배치
- 링크장 도면을 터치하면 파란 점으로 슛 위치 표시
- 골대 도면을 터치하면 기존처럼 빨간 점으로 실점 위치 표시
- 슛 위치를 자동으로 간단한 구역명으로 분류
  예: 로우 슬롯 / 하이 슬롯 / 좌측 페이스오프 서클 / 포인트 / 블루라인 부근
- 경기 상세 및 공유 텍스트에도 슛 위치 + 실점 위치 표시
- 기존 경기 데이터는 그대로 호환
