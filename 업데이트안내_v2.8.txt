Goalie Tracker Pro v2.8

수정 내용
1. 슛 위치 하프링크가 잘리던 문제 수정
   - SVG 실제 비율 760:640에 맞춰 컨테이너 비율 통일
   - 링크장/그리기 레이어/터치 레이어를 정확히 같은 크기로 고정
   - 터치 좌표 어긋남 보정

2. 실점 위치
   - 골리 일러스트 제거
   - 기존처럼 골대만 표시
   - 실점 위치는 점으로만 체크

3. 게임레슨 실점 분석
   - GOAL + 입력 시 그 골리의 실점 분석 항목 자동 생성
   - 골리 이름과 A/B 골대 자동 표시
   - 발생 상황 / 공격 형태 / 마무리 / 짧은 메모 기록
   - GOAL - 시 최근 실점 분석도 함께 제거
   - 이전 교대 기록에서 G+ / G- 수정해도 분석 항목과 연동
   - 경기 상세에서도 게임레슨 실점 분석 확인
   - 시즌 통계에서 게임레슨 필터 선택 시 해당 분석 데이터도 집계
