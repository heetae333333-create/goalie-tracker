Goalie Tracker Pro v2.6

추가/개선 사항
1. 실점 분석의 슛 위치 링크장을 하프링크 아래 골대 기준 도면으로 변경
2. 슛 위치 입력을 점 찍기에서 그리기 방식으로 업그레이드
   - 점
   - 선
   - 자유그리기
   - 실행취소
   - 전체 지우기
3. 실점 위치 골대 그림을 더 직관적인 골리 일러스트 스타일로 변경
4. 실점 위치는 기존처럼 점으로 간단히 체크
5. 발생 상황 / 공격 형태 / 마무리 구조를 더 체계적으로 정리
   - 러시, 오드맨 러시, 브레이크어웨이, 턴오버, 디펜스슛, 존 플레이, 리바운드, 스크램블, 비하인드 넷, 스페셜팀
6. 기존 기록 수정 화면의 경기 분류/그룹 기능 유지

업데이트 후 확인
- 홈 화면에 v2.6 표시
- 실점 분석에서 하프링크가 아래 골대 기준으로 보이는지 확인
- 점 / 선 / 자유 도구로 슛 위치를 그릴 수 있는지 확인
- 오른쪽 골대 그림에서 실점 위치를 점으로 찍을 수 있는지 확인
